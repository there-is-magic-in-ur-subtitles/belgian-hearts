# Tinder-style mobile swipe app

## Build
- Create one standalone HTML file containing all markup, styling, profile data, and vanilla JavaScript.
- Lock the experience to an iPhone SE–sized 325×568 canvas while keeping it centered and usable in larger previews.
- Recreate the requested header, layered profile cards, photo progress bars, profile overlay, and four bottom actions.

## Interaction
- Add left/right photo tap zones with per-profile photo progress.
- Add touch and pointer dragging, swipe thresholds, off-screen animations, and X/Heart button swipes.
- Make Undo restore the previous profile, Star advance with its own animation, and loop seamlessly after profile 25.

## Content and assets
- Include 25 fictional adult male profiles located around Brussels, Belgium.
- Use local portrait artwork with weapon-themed poses; reuse and vary the generated assets across profiles to keep the deliverable self-contained.
- Keep every image embedded or local so the app does not depend on hotlinked placeholder services.

## Preview and verification
- Make the project’s root page open the standalone app.
- Verify the exact 325×568 layout and the photo taps, drag gestures, buttons, and looping behavior in mobile Safari dimensions.
